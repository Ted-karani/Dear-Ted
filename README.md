# Dear Ted

A private space to heal, remember, and become. React + Vite, saved in your browser.

## Run it
    npm install
    npm run dev        # open the address it prints
    npm run build      # makes the dist/ folder
    npm run preview    # try the built version

## Deploy to Vercel
1. Put the project on GitHub.
2. In Vercel choose "Add New Project" and import the repository.
3. Keep the defaults (Vite is detected) and press Deploy. `vercel.json` already handles page refreshes.

## Privacy
Entries live in each browser's localStorage. They are not encrypted, not synced between devices, and not sent anywhere. A public URL does not upload your data.

## What is included
Home (daily reminder, mood check-in), Dear Ted letter, Letters & Our Story, Memory Archive, When I Miss Her, Private Journal, Faith & Gratitude, My Healing Journey, Future Me, Music & Quiet Moments, Settings (themes, export, import, reset).

## Notes
- Sounds are generated by the browser. You can also play your own audio file.
- Photos in the Memory Archive are shrunk before saving because browser storage is limited.
